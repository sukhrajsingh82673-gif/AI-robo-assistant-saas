# FINAL_ARCHITECTURE_DECISION_RECORD

Status values: **Proposed** (needs human approval) · **Accepted-by-design** (follows from the brief's hard rules). Evidence tags as in `OPEN_SOURCE_EVALUATION.md`.

| ADR | Decision | Status | Reasons | Consequences / alternatives rejected |
|---|---|---|---|---|
| **ADR-001** | The Factory is a **subsystem of ZONATA behind ports**; no own identity, approval, audit, workforce or policy engine | Accepted-by-design | Brief §1.2 and rules 3/5/6; a second authority would be a bypass path | Port adapters needed; if governance is a stub, fix it in ZONATA core (stop-the-line), not in the Factory |
| **ADR-002** | Agents are **declarative `zonata.agent/v1` specs compiled to LangGraph**; model output never executes as backend code | Proposed | Removes largest attack surface; deterministic, diffable builds; matches bagalsharad ADR approach `[SRC]` | Code-writing agents only as sandboxed *tool packages*. Rejected: Mozilla-style generated Python agents (`[SRC]`: executable `imports/tools` fields) |
| **ADR-003** | **LangGraph (library) is the only runtime**; not LangGraph Server/LangSmith | Accepted-by-design | Brief rule 4; Server/LangSmith proprietary `[WEB]` | CrewAI/Agno/ADK/OpenAI SDK/MS AF/Pydantic AI not adopted as runtimes (duplicate orchestration) |
| **ADR-004** | **No LLM holds a gate**: Director, QA Director, Certification Manager, Release Manager are deterministic services | Proposed | LLMs are persuadable; thresholds are not | Less "autonomy flair", more auditability |
| **ADR-005** | **Separation of duties enforced in service, FGA and DB** (requester ≠ approver; builder ≠ evaluator) | Accepted-by-design | Brief Part 6/11; DB triggers verified on PG16 | Slight duplication is intentional defence in depth |
| **ADR-006** | **Mozilla agent-factory: REJECT as dependency**; adapt only ideas (eval-case synthesis, tested MCP catalogue) | Proposed | Last commit 2025-10-20; Python ≥3.13; pins old `any-agent`; code-generation model; no governance `[SRC]` | Nothing from it is vendored |
| **ADR-007** | **bagalsharad/agent_factory: ADAPT** — reference + vendor reviewed modules (spec, validator, templates, eval checks, gate logic) under Apache-2.0 with NOTICE; never a runtime dependency; **not** its governance/auth/queue/UI | Proposed | Same philosophy; 20.6k LOC, 28 test files `[SRC]`; but alpha (17 commits/4 days), single author, AI-built, tests unverified by us `[SRC][CLAIM]` | Requires review + test run before vendoring; alternative (build everything from scratch) costs weeks |
| **ADR-008** | **Orchestration through `OrchestratorPort`**: Temporal if deployed; else Postgres `DbQueueOrchestrator` | Proposed | Temporal fits long-running manufacturing (MIT `[SRC]`) but cannot run on free tiers; same acceptance tests for both | Two adapters to maintain; DB-queue is the fallback, not the target for scale |
| **ADR-009** | **Postgres RLS** (`FORCE`, non-owner role, per-transaction tenant setting) on every `af_*` table | Proposed | Tenant isolation as a database property; verified RLS read/write/fail-closed on PG16 | Must use `SET LOCAL` with poolers; mirror existing boundary if different (tenant vs company) |
| **ADR-010** | **Immutability via triggers** for agent versions (spec/permissions), artifacts, certifications, results, events, decided releases | Proposed | Product promise (“production agents never silently change”) | Corrections = new rows/versions |
| **ADR-011** | **Evidence-before-effect**: `af_lifecycle_event.evidence_ledger_id NOT NULL`; ledger stays source of truth | Accepted-by-design | Brief Part 11 (#10) | A ledger outage halts transitions (fail-closed) |
| **ADR-012** | **Signing:** Ed25519 detached signatures over canonical JSON; key in Vault/OpenBao; verified at publish and at runtime load; cosign only for container images later | Proposed | Simple, offline-verifiable, free-tier friendly; Sigstore public-good infra adds operational dependency | Key custody becomes critical (R-17) |
| **ADR-013** | **QA = own thin harness + Langfuse tracking**; promptfoo/DeepEval/garak/PyRIT optional & pinned; mock results never certify | Proposed | Control over independence/held-out/gating; avoids vendor drift (promptfoo→OpenAI `[WEB]`) | More code to own; datasets portable |
| **ADR-014** | **Sandbox tiers T0/T1/T2**; T0 default; T2 mandatory for model-written/imported code; disabled when unavailable | Proposed | Honest isolation; free tier cannot provide T1/T2 | Tool authoring/Import lane arrive only with suitable hosts |
| **ADR-015** | **Risk tiers R0–R3 computed, not declared**; approval matrix by tier; autonomy modes only tighten | Proposed | Maps onto owner's existing autonomy settings | Some friction on R2/R3 by design |
| **ADR-016** | **Atomic team publication** default for teams; `independent` for multi-agent sets; subset release only by human-approved new manifest | Proposed | No half-live teams; explicit partial-failure semantics | Longer time-to-publish for large teams |
| **ADR-017** | **Storage behind S3 port; MinIO not used for new deployments** | Proposed (human decision) | MinIO CE repo archived 2026-04-25 `[WEB]` | Pick SeaweedFS (Apache-2.0) or managed S3-compatible; verify before choosing |
| **ADR-018** | **Secrets behind `SecretsPort`; evaluate OpenBao** | Proposed (human decision) | Vault is BSL 1.1; OpenBao MPL-2.0 under OpenSSF/LF `[WEB]` | Legal decision; CI to test both |
| **ADR-019** | **Existing-factory migration by strangler pattern** if Phase 1 finds one | Proposed | Preserve behaviour (rule 5/17) | `legacy_agent_id` mapping; no deletion |
| **ADR-020** | **Import lane for external OSS agents is quarantined and convert-to-spec only** | Proposed | Owner's design (download from GitHub) conflicts with host safety unless sandboxed | Disabled without T2 |
| **ADR-021** | **Agents never use employees** encoded in schema, FGA type model and tests | Accepted-by-design (owner rule) | Owner's design principle | `may_use_employees` fixed `false` |
| **ADR-022** | **API namespace follows the highest existing version in repo** (not assumed `v9`) | Accepted-by-design | Brief says evaluate | Recorded in Phase 1 |
| **ADR-023** | **Gate policy as versioned file; Factory read-only to it; changes need AI CEO + human owner** | Proposed | Prevents factory/LLM from weakening gates | Calibration changes are deliberate events |
| **ADR-024** | **Free-tier honesty**: features needing unavailable infra are flag-disabled and reported by `/ready`; readiness report lists unvalidated items | Accepted-by-design | Brief Part 17 | Pilot scope limited to T0 agents until infra exists |
